# Milestone 29 — Reveal Completed Output

## Goal

Make it easy to locate a validated output without manually navigating to the saved destination folder.

## Step 1 — Show in Finder

After a conversion completes and the validated partial file has been promoted to its final filename, the completion summary now offers **Show in Finder**. The action asks macOS Finder to open the containing folder and select that exact output.

The button is only present for a successfully completed conversion. Cancelled, failed, and incomplete outputs retain their existing explicit recovery controls instead.

The Debug build succeeded. After a real conversion completed, the user clicked **Show in Finder** and confirmed that Finder opened the correct output folder with the completed MP4 selected. Milestone 29 is complete.
